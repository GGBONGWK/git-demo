# git-demo

这是我用来练习 Git 与 GitHub 的第一个仓库。

## 内容

- `hello.py` —— 一个打印问候语的小脚本
- `.gitignore` —— 告诉 Git 哪些文件不要提交

## 常用命令

```bash
git status                  # 看当前状态
git add .                   # 把改动放进暂存区
git commit -m "说明"        # 存成一个版本
git push                    # 推到 GitHub
```

## 运行

```bash
python hello.py
```
